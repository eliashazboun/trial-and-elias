# Asset and dependency notices

The felt, cards, chip textures and audio are original programmatic assets generated by this application. No external card artwork, recorded music, downloaded fonts or live asset URLs are required. Source reference charts were inspected privately; their images are not bundled.

The local Button/Dialog components follow the MIT-licensed shadcn/ui local-source pattern using Radix primitives, cva, clsx and tailwind-merge. Lucide icons retain their library license.
